# Modern Calculator

A polished Android-friendly calculator designed to work offline first.

## Features
- Basic arithmetic with correct order of operations
- Parentheses, percentage, sign toggle, decimal and backspace
- Scientific functions: sin, cos, tan, log, ln, square root, powers and pi
- DEG/RAD angle modes
- Calculation history saved locally
- Memory: MC, MR, M+, M−
- Dark, light and system themes
- Haptic feedback toggle
- Copy/share result
- Offline unit conversion
- Optional live currency conversion when internet is available
- Keyboard support

Core calculator functionality does not require an internet connection.

## Android packaging
This is a web app prepared for Capacitor packaging. APK generation is intentionally not included yet.
